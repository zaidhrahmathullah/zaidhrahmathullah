## 🚀 Featured Project

### ClothingMart — Full-Stack E-Commerce Platform

A full-stack e-commerce application built to demonstrate practical software engineering skills across frontend development, backend architecture, database management, and payment processing.

**Key Features**
- Responsive product browsing and category filtering
- JWT-based authentication and role-based access control
- Shopping cart, wishlist, and checkout
- Address and order management
- PayPal payment integration
- Admin dashboard for product and order management
- PostgreSQL database with Prisma ORM

**Technologies:** Next.js · TypeScript · Node.js · Express.js · PostgreSQL · Prisma · Tailwind CSS

🔗 **[Live Application](https://clothingmart.vercel.app/)**
