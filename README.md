### 1. ClothingMart — Full-Stack E-Commerce Platform

A full-stack e-commerce application featuring a customer storefront, secure authentication, payment processing, and administrative management.

**Key Features**
- Responsive product browsing, categories, and product variants
- JWT authentication and role-based access control
- Shopping cart, wishlist, checkout, and order management
- PayPal Sandbox payment integration with server-side verification
- Admin dashboard for product, inventory, order, and payment management
- RESTful API built with Express.js
- PostgreSQL database managed with Prisma ORM

**Technologies:** Next.js · TypeScript · Node.js · Express.js · PostgreSQL · Prisma · Tailwind CSS · PayPal Sandbox

### 2. Sri Lanka Destination Explorer — Full-Stack Travel Discovery Application

A full-stack travel discovery platform for exploring destinations across Sri Lanka, featuring live weather information and a secure administration dashboard.

**Key Features**
- Responsive destination browsing and detailed destination pages
- Current weather information powered by the Open-Meteo API
- Modular REST API developed using NestJS
- MongoDB database integration with Mongoose
- Secure administrator authentication using JWT and HTTP-only cookies
- Protected admin dashboard with destination CRUD operations
- Next.js same-origin API proxy for production authentication
- Frontend, backend, and database deployed using Railway

**Technologies:** Next.js · React · TypeScript · Tailwind CSS · NestJS · MongoDB · Mongoose · JWT · Open-Meteo · Railway

🔗 **[Live Application](https://srilanka-destination-explorer.up.railway.app)**

📂 **[Source Code](https://github.com/zaidhrahmathullah/srilanka-destination-explorer)**
